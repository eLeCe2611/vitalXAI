# Capítulo 8: Temas abiertos y decisiones pendientes

A fecha de elaboración del presente documento, los temas pendientes han quedado reducidos a los siguientes, tras la toma de las decisiones que se describen a continuación.

**Dataset de entrenamiento**: Este documento concluye el tema. El sistema utilizará el conjunto de datos público de radiografías de tórax pediátricas publicado por Kermany y colaboradores, procedente del Guangzhou Women and Children's Medical Center y disponible en Kaggle. Este dataset contiene 5.856 radiografías en formato JPEG, clasificadas en dos categorías: NORMAL (1.583 imágenes) y PNEUMONIA (4.273 imágenes), estas últimas subdivididas en neumonía bacteriana y viral. Se ha seleccionado este conjunto por ser el mismo utilizado en el estudio de referencia (Kermany & al., 2018), lo que permite establecer una comparación directa con los resultados publicados. El desbalanceo natural entre clases se abordará mediante la técnica de submuestreo aleatorio en cada pliegue de la validación cruzada, garantizando particiones balanceadas.

**Dataset de validación externa**: Este documento concluye el tema. Se empleará el conjunto de datos COVID-19 Radiography Database, desarrollado por investigadores de la Universidad de Qatar y la Universidad de Dhaka, que contiene radiografías de tórax de pacientes adultos. Para la validación externa se extraerán 500 imágenes de pacientes sanos y 500 imágenes de pacientes con neumonía viral, garantizando un balance perfecto entre clases. Este dataset ha sido seleccionado porque representa una población diferente (adultos frente a niños), con equipos de adquisición y protocolos de imagen distintos, lo que constituye un escenario exigente para evaluar la capacidad de generalización de los modelos.

**Arquitecturas de deep learning**: Este documento concluye el tema. El banco de pruebas estará compuesto por dieciséis arquitecturas convolucionales (ResNet50, ResNet101, ResNet152, ResNet50V2, EfficientNetB0, EfficientNetB3, EfficientNetB7, EfficientNetV2S, DenseNet121, DenseNet201, MobileNetV2, MobileNetV3Large, VGG16, InceptionV3, Xception y ConvNeXtTiny) y tres arquitecturas Transformer (DeiT, Swin-Base y ViT-384). Esta selección cubre un espectro representativo de enfoques arquitectónicos, desde modelos ligeros como MobileNetV2 hasta modelos de alta capacidad como ConvNeXt-Tiny y los Vision Transformers.

**Técnicas XAI**: Este documento concluye el tema. Se implementarán tres técnicas de inteligencia artificial explicable: Saliency Maps, SmoothGrad y Grad-CAM (para CNN) o mapas de atención (para Transformer). Para la evaluación cuantitativa de las explicaciones se calcularán las métricas Deletion AUC, Insertion AUC, Sparsity, Entropy y Stability SSIM. Adicionalmente, se incorporará la métrica Expected Calibration Error (ECE) para evaluar la calibración de las predicciones.

**Tecnologías del sistema**: Este documento concluye el tema. El backend se desarrollará con FastAPI y Python, el frontend con HTML, CSS y JavaScript vanilla, la base de datos con MySQL, el motor de deep learning con TensorFlow y Keras, y los modelos Transformer con HuggingFace Transformers. El asistente conversacional se integrará mediante la API de Groq con el modelo Llama 3. No se utilizarán frameworks de frontend adicionales (React, Vue, Angular) para mantener la simplicidad del sistema y facilitar su mantenimiento.
